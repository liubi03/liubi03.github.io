# 一、引言

## 1.1 语言模型发展历程

分成四个阶段：

1. 统计语言模型(Statistical Language Model, SLM)：基于统计语言模型，使用马尔可夫假设，n 元 (n-gram)语言模型，下一个词的概率只和前n个词有关。n的增加，会带来维度灾难。
2. 神经语言模型(Neural Language Model, NLM)：使用神经网络来建模文本序列的生成，用**低维稠密向量**表示词——"词嵌入"（Word Embedding），语义相近的词，向量也相近
3. 预训练语言模型(Pre-trained Language Model, PLM)：增加了上下文感知，能够有效捕捉上下文语义。传统LSTM**训练过慢，只能串行训练，*****长文本建模能力弱**。Transformer 架构推出，BERT只有编码器，GPT系列只有解码器，这是预训练-微调范式的起点
4. 大语言模型(Large Language Model, LLM)：
   1. “**扩展法则**”(Scaling Law)：通过规模扩展  (如增加模型参数规模或数据规模)通常会带来下游任务的模型性能提升。
   2. **涌现能力**：大模型具有但小模型不具有的能力

## 1.2 大语言模型的能力特点

1. 世界知识丰富
2. 通用任务解决能力强，提示学习能力强
3. 复杂任务推理能力强
4. 遵循人类指令
5. 具有较好的人类对齐能力
6. 工具使用能力还是需要扩展

## 1.3 大语言模型关键技术

1. 模型规模扩展
2. 数据的规模预质量
3. 预训练的效率
4. 质量微调、提示学习等利用激发大模型能力
5. 人类对齐，对齐人类价值观，防止隐私泄露等。 强化学习
6. 工具使用：指令微调、提示学习

# 第二章 基础介绍

## 2.1 大语言模型的构建过程

大语言模型是一种基于 Transformer 结构的神经网络模型

训练过程一般分为两个阶段：

1. 大规模预训练
2. 指令微调与人类对齐

### 2.2.1 大规模预训练

准备大规模的文本数据

-> 清洗数据，去除可能包含有毒有害的内容

-> 分词器切成token

-> 切分成batch，用于预训练

### 2.1.2 指令微调和人类对齐

比较广泛使用的微调技术是“指令微调”(也叫做有监督微调,  Supervised Fine-tuning, **SFT**),通过使用任务输入与输出的配对数据进行模型训练，本质属于机器学习中的模仿学习

强化学习，RLHF 算法：

- 需要训练一个符合人类价值观的奖励模型，需要标注人员针对大语言模型所生成的多条输出进行偏 好排序,并使用偏好数据训练奖励模型,用于判断模型的输出质量
- 强化学习需要维护更多的辅助模型进行训练,通常来说对于资源的消耗会多于指令微调, 但是也远小于预训练阶段所需要的算力资源

## 2. 2 扩展法则

- KM扩展法则（OpenAI，2020）：分别刻画损失与参数量、数据量、算力的幂律关系，指数小、收益递减明显
  - 核心结论：算力增加时倾向优先堆参数（参数比数据重要），导致GPT-3数据严重不足
- Chinchilla扩展法则（DeepMind，2022）：联合刻画参数量和数据量对损失的影响，在固定算力下求最优分配
  - 核心结论：**参数和数据应等比例增长（约20:1）**，纠正了“数据被忽视”的问题，70B模型可超过280B的Gopher
- 两者本质差异：KM倾向堆参数，Chinchilla主张参数数据同步增长
- 实践修正：20:1比例已过时，LLaMA-2 7B用2T词元仍未饱和，Transformer数据扩展性极好
- 现实约束：公共文本将枯竭，数据重复与合成数据成为研究方向

## 2.3 涌现能力

代表性的涌现能力：

1. 上下文学习

   **上下文学习能力还取决于具体的下游任务**。例如,13B 参数的 GPT-3 模型可以在算术任务(例如 3 位数的加减法)上展现出上下文学习能力,但 175B 参数的 GPT-3 模型在波斯语问答任务上甚至不能表现出良好的性能

2. 指令遵循：语言模型能够按照自然语言指令来执行对应的任务

   为了获得这一能力,通常需要使用自然语言描述的多任务示例数据集进行微调,称为**指令微调**

   有实验在**模型参数规模达到 62B 及 以上的情况，才能展现出较好的零样本推理能力**

   **小模型只能展现出一部分**

3. 逐步推理

   大语言模型则可以利用**思维链 (Chain-of-Thought, CoT)**提示策略：在**提示中引入任务相关的中间推理步**骤来加强复杂任务的求解,从而获得更 为可靠的答案
